# Skrinshoter

Windows-приложение для скриншотов и записи экрана. Эта версия работает без подписок, платных ограничений, рекламы и интеграции Heybro.

## Возможности

- скриншоты области, окна, монитора и всего рабочего стола;
- встроенный редактор изображений;
- запись экрана;
- сохранение на диск или копирование изображения в буфер обмена;
- загрузка в Скриншотер, kappa.lol, Xyli, 0xl1r.cfd и NoikCloud;
- одновременная загрузка во все отмеченные сервисы;
- копирование полученных ссылок и открытие их в браузере.

В редакторе `Enter` загружает изображение только в Скриншотер. `Ctrl+Enter` по умолчанию загружает его во все сервисы, отмеченные в настройках. Комбинацию можно изменить на вкладке «Горячие клавиши».

## Готовые варианты

- `Skrinshoter-portable-win-x64.zip` — переносимая версия без установки;
- `Skrinshoter-setup-win-x64.exe` — установка для текущего пользователя с поддержкой удаления;
- `SHA256SUMS.txt` — контрольные суммы релизных файлов.

Для запуска требуется Windows 10/11 x64 и .NET Framework 4.8.

## Сборка

Откройте PowerShell в корне проекта:

```powershell
.\build.ps1
```

Сборка полного релиза, включая portable ZIP, установщик, архив исходников и контрольные суммы:

```powershell
.\release.ps1
```

При первом запуске сценарий локально устанавливает требуемый .NET SDK в `.dotnet`, а Inno Setup — в `.tools`. Эти каталоги не попадают в Git.

## Исходный код и лицензирование

Проект реконструирован из поставляемых .NET-сборок. Перед публичной публикацией владелец репозитория должен добавить лицензию, соответствующую его правам на исходный продукт и используемые компоненты. Лицензия FFmpeg включается в готовую сборку рядом с модулем записи.

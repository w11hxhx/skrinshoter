# Скриншотер 4.87.4.5

## Исправления и улучшения

- Исправлено распознавание текста, когда установленные языки OCR не входят в список предпочитаемых языков Windows: используется доступный распознаватель.
- Улучшена обработка ошибок OCR, Unicode-путей и отсутствующих изображений. Процесс распознавания завершается при отмене или превышении времени ожидания.
- Внешние и пользовательские сервисы теперь загружают скриншот параллельно. Ссылки сохраняют порядок сервисов; сбой или отмена одного сервиса не теряет успешные результаты остальных.
- Во время загрузки можно сделать следующий скриншот. Завершение старой загрузки не закрывает новый редактор и не сбрасывает его состояние.
- Окна прогресса параллельных загрузок располагаются друг над другом. Временные файлы удаляются только после завершения всех загрузчиков.
- Добавлены автоматические проверки OCR, параллельной отправки, частичных ошибок, отмены и состояния захвата.

## Скачать

- **Skrinshoter-setup-win-x64.exe** — установщик.
- **Skrinshoter-portable-win-x64.zip** — переносная версия без установки.
- **Skrinshoter-source.zip** — исходный код.
- **SHA256SUMS.txt** — контрольные суммы файлов.

Требуются Windows 10/11 x64 и .NET Framework 4.8. Для OCR нужен хотя бы один установленный язык распознавания Windows.

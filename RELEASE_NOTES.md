# Скриншотер 4.87.4.8

## Переход с официальной версии

- Установщик обнаруживает официальную версию Скриншотера в пользовательских и системных записях удаления Windows (32/64 бит).
- Перед удалением сохраняется резервная копия настроек. После удаления настройки восстанавливаются без изменения биндов.
- Резервная копия остаётся в `%LOCALAPPDATA%\Skrinshoter-fork-migration` для ручного восстановления при необходимости.
- Если создать копию невозможно, удаление не начинается. При отмене или ошибке удаления официальной версии установка форка останавливается с сохранением настроек.
- Для удаления официальной версии из Program Files Windows может запросить повышение прав. Сам форк по-прежнему устанавливается в пользовательскую папку.
- Обновления уже установленного форка не запускают удаление самого форка.
- Добавлены изолированные проверки реального установщика и проверка сохранения всех шести нестандартных биндов скриншотов и записи.

## Скачать

- **Skrinshoter-setup-win-x64.exe** — установщик.
- **Skrinshoter-portable-win-x64.zip** — переносная версия; она не удаляет установленные программы.
- **Skrinshoter-source.zip** — исходный код.
- **SHA256SUMS.txt** — контрольные суммы файлов.

Требуются Windows 10/11 x64 и .NET Framework 4.8.

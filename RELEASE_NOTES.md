# Скриншотер 4.87.4.2

## Что нового

- Убрана всплывающая надпись «Скриншотер» при наведении на значок в трее, которая могла оставаться на экране.
- Добавлена настройка «Оставлять названия сервисов в ссылках». Если её отключить, в буфер обмена копируются только ссылки без префиксов вроде «Скриншотер:».
- Добавлена кнопка распознавания текста на скриншоте. Распознавание выполняется локально средствами Windows, результат копируется в буфер обмена. Используются установленные языки распознавания Windows.
- В настройках можно показывать и скрывать каждую кнопку редактора: загрузку, копирование, печать, сохранение, инструменты рисования, распознавание текста и поиск по фото.
- Добавлен поиск по скриншоту через Яндекс Картинки, Google Lens, Bing Visual Search и TinEye. Нужные сервисы выбираются в настройках, результаты открываются в браузере. Для поиска изображение загружается на kappa.lol.
- Кнопка «Сообщить об ошибке» теперь открывает Telegram: https://t.me/wiihxhx.

## Скачать

- **Skrinshoter-setup-win-x64.exe** — установщик.
- **Skrinshoter-portable-win-x64.zip** — переносная версия без установки.
- **Skrinshoter-source.zip** — исходный код.
- **SHA256SUMS.txt** — контрольные суммы файлов.

Требуются Windows 10/11 x64 и .NET Framework 4.8.

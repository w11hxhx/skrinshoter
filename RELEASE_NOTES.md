# Скриншотер 4.87.4.7

## Обновления форка

- Удалены проверки обновлений, анонсы и скачивание установщика официальной версии. Источник обновлений — только GitHub-релизы w11hxhx/skrinshoter.
- При появлении новой версии предлагается окно с описанием изменений из релиза и текущей/новой версией.
- Скачивание и установка начинаются только после нажатия «Скачать и установить». Доступны «Позже / закрыть», «Пропустить версию» и отключение автоматической проверки.
- Загрузку можно отменить. Закрытие окна также отменяет незавершённую загрузку; текущая версия остаётся на месте.
- Перед запуском установщика проверяются размер и SHA-256, опубликованные GitHub. После скачивания открывается обычный мастер установки с возможностью отмены.
- Проверка обновлений вручную доступна из меню в трее и раздела «О программе», даже если автоматическая проверка отключена.
- Обновление не запускается во время захвата или записи экрана. Предварительные релизы, текущая и более старые версии не предлагаются.

## Скачать

- **Skrinshoter-setup-win-x64.exe** — установщик.
- **Skrinshoter-portable-win-x64.zip** — переносная версия.
- **Skrinshoter-source.zip** — исходный код.
- **SHA256SUMS.txt** — контрольные суммы файлов.

Требуются Windows 10/11 x64 и .NET Framework 4.8. Уже установленную версию 4.87.4.6 или старше нужно один раз обновить этим установщиком, чтобы переключиться на обновления форка.

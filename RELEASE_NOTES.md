# Скриншотер 4.87.4.6

## Исправления

- Исправлена ошибка установщика «CreateProcess: сбой; код 740. Запрошенная операция требует повышения» при запуске приложения после установки.
- Приложение и модуль записи больше не запрашивают UIAccess. Установка в пользовательскую папку и запуск portable-версии не требуют повышения прав.
- Добавлена проверка встроенных манифестов обоих EXE перед упаковкой: сборка останавливается, если они требуют повышения прав или UIAccess.
- Сохранены исправления OCR и фоновая параллельная загрузка из версии 4.87.4.5.

- **Skrinshoter-setup-win-x64.exe** — установщик.
- **Skrinshoter-portable-win-x64.zip** — переносная версия без установки.
- **Skrinshoter-source.zip** — исходный код.
- **SHA256SUMS.txt** — контрольные суммы файлов.

Требуются Windows 10/11 x64 и .NET Framework 4.8.
